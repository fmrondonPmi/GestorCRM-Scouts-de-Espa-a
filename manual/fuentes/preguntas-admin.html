Preguntas frecuentes

«Probar conexión» falla.

Revisa la URL (la dirección base del CRM, sin rutas), el usuario y la contraseña. Si el mensaje dice que el usuario no ve el grupo, pide a ASDE permisos sobre ese grupo. La contraseña no se vuelve a mostrar: si dudas, escríbela de nuevo.

Las fichas salen todas en solo lectura.

El usuario de API del grupo no tiene permiso de edición en el CRM. Con permiso de lectura el área funciona, pero no se puede guardar nada. «Probar conexión» dice en qué módulos puede escribir.

¿Puedo usar otro tema que no sea Enfold?

Sí. Elige uno que permita páginas a ancho completo, sin barra lateral ni barra de título, y revisa las pantallas del área antes de cambiarlo en una web en uso.

Una traducción no suena bien.

Cámbiala en «Idioma y etiquetas», en la pestaña de ese idioma: tu texto manda sobre el del plugin y se conserva al actualizar.

Queremos que todo salga en catalán.

Elige el catalán como idioma por defecto. Si además no quieres que cada persona pueda cambiarlo, desmarca «Dejar que cada persona elija su idioma».

¿Los colores se pueden poner por grupo?

No: valen para toda la web. Si la web lleva varios grupos, todos comparten los colores.

Quiero pasar a usar el nº de Scouts de España como usuario.

En «Organización federada», elige ese usuario de acceso y, debajo, revisa y confirma el renombrado de las cuentas existentes. Las personas pueden seguir entrando con el número de siempre.

¿Cómo instalo una versión nueva?

En Plugins, sube el zip de la versión nueva («Subir plugin» y «Reemplazar el actual»). Después mira «Instalación y entorno»: lo nuevo se crea solo y la pantalla avisa si falta algo.
